# devin-web v0.1.2

This maintenance release fixes service-control and storage failure modes found in the v0.1.1 review.

- A process record whose boot ID or start time no longer matches its PID is treated as stale and cleaned without signalling. PID reuse no longer blocks `ctl start` or the watchdog. Other ownership mismatches still fail closed and now report which fields differ.
- The web watchdog and idle-restart watcher remove their own records when stopped, so a normal `ctl stop` leaves no launch files behind. The SIGTERM grace period is back to about five seconds.
- An unreadable `itemlog.db` no longer blocks turn finalization or the prompt queue; provisional turns stay in memory only, and persistence stays disabled for the rest of that web process, so restart the web (when no turn is active) after repairing the file. Failed writes to an open log still preserve the region and retry.
- `ctl acpd restart --when-idle` reports success only after its watcher is running. Deferred turn completions keep their token usage, and the transcript view re-runs a refresh requested while another is in flight.
- Git hook installation skips with a notice when `core.hooksPath` comes from global, system, or command-line configuration, instead of writing `pnpm verify` into a hooks directory shared by every repository.

## Upgrade

Supports Linux and Linux on WSL, Node >=24.18.0 <25, and pnpm 9.15.9. Devin CLI must be installed and authenticated separately. Verify the source archive against SHA256SUMS; manifest.json identifies its source commit and packaging tools.

No configuration or state-format change. Rebuild and run `bin/devin-web-ctl restart` to apply the web changes; running turns and the daemon are preserved and no daemon restart is required. Watcher processes already running keep their previous code until they are next started. The release does not automatically update a running installation.

## 한국어

v0.1.1 리뷰에서 확인한 서비스 제어·저장소 장애 문제를 수정한 유지보수 릴리스입니다.

- PID의 boot ID나 시작 시각이 기록과 다르면 stale 기록으로 판단해 신호 없이 정리합니다. PID가 재사용되어도 `ctl start`와 워치독이 막히지 않습니다. 그 밖의 소유권 불일치는 계속 거부하며 어떤 필드가 다른지 알려 줍니다.
- 웹 워치독과 idle-restart 감시 프로세스가 종료될 때 자신의 기록을 지웁니다. 정상 `ctl stop` 뒤에 launch 파일이 남지 않으며, SIGTERM 유예 시간은 다시 약 5초입니다.
- `itemlog.db`를 열 수 없어도 턴 정리와 프롬프트 대기열이 멈추지 않습니다. 진행 중인 턴은 메모리에만 보관되고, 해당 웹 프로세스가 끝날 때까지 저장은 비활성 상태로 유지되므로 파일을 복구한 뒤 진행 중인 턴이 없을 때 웹을 재시작하세요. 열린 로그에 대한 쓰기 실패는 기존처럼 영역을 보존하고 재시도합니다.
- `ctl acpd restart --when-idle`은 감시 프로세스가 실제로 실행된 뒤에만 성공을 보고합니다. 지연된 턴 종료도 토큰 사용량을 유지하고, 진행 중 요청과 겹친 대화 기록 새로고침은 다시 실행합니다.
- `core.hooksPath`가 전역·시스템·명령줄 설정에서 오면 hook 설치를 안내와 함께 건너뜁니다. 모든 저장소가 공유하는 hook 디렉터리에 `pnpm verify`를 쓰지 않습니다.

설정이나 상태 형식 변경은 없습니다. 웹 변경은 빌드 후 `bin/devin-web-ctl restart`로 적용하며 진행 중인 작업과 데몬은 유지됩니다. 데몬 재시작은 필요하지 않습니다. 이미 실행 중인 감시 프로세스는 다시 시작할 때까지 이전 코드를 사용합니다. 이 릴리스는 기존 서비스를 자동으로 업데이트하지 않습니다.

Linux·WSL의 Linux 환경, Node >=24.18.0 <25, pnpm 9.15.9를 지원합니다. 별도 Devin CLI 설치·로그인이 필요합니다. 설치 전 SHA256SUMS를 검증하고 manifest.json의 소스 커밋을 확인하세요.
