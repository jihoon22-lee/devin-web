# devin-web v0.1.0

The first public source release of the local web interface for Devin CLI.

- Browse and search session history, stream agent responses, answer permission requests, and use persistent terminals.
- Managed daemon mode preserves running agent turns and terminals across web restarts.
- Loopback-only defaults, isolated browser tests, restart preflight checks, and documented backup and recovery.

Supports Linux and Linux on WSL with Node 24.18.x (Node >=24.18.0 <25) and pnpm 9.15.9. A separately installed and authenticated Devin CLI is required. Read README.md or docs/getting-started.md in the source archive. Verify SHA256SUMS before installation. The manifest records the exact source commit and packaging tools.

This is a local trusted-user application with access to files and a shell. It does not provide internet-facing authentication. Keep its listener on loopback; review SECURITY.md before remote access. No npm package or automatic deployment is included.

## 한국어

Devin CLI를 위한 로컬 웹 인터페이스의 첫 공개 소스 릴리스입니다.

- 세션 기록 탐색·검색, 응답 스트림, 권한 요청 응답, 지속되는 터미널을 제공합니다.
- 데몬 운영 모드에서는 웹을 재시작해도 실행 중인 에이전트 작업과 터미널을 유지합니다.
- 기본 루프백 바인딩, 격리된 브라우저 검사, 재시작 사전검사, 백업·복구 문서를 포함합니다.

Linux 및 WSL의 Linux 환경, Node >=24.18.0 <25, pnpm 9.15.9를 지원합니다. Devin CLI를 별도로 설치하고 로그인해야 합니다. 소스 압축물의 README.ko.md에서 시작 안내를 확인하고 설치 전 SHA256SUMS를 검증하세요. manifest에는 정확한 소스 커밋과 도구 버전이 기록됩니다.
