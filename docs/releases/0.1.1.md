# devin-web v0.1.1

This maintenance release strengthens file recovery, session isolation, and restart safety.

- Discard and Undo preserve symbolic links, file modes, and both paths of a rename. Recovery remains available when Git cannot complete a discard.
- Terminal input, history responses, failed sends, and search jumps stay with their originating session. Explicit search targets never fall back to matching text elsewhere.
- The final thought/plan state is saved before a turn is retired. Queue draining waits for all outstanding prompts, including after a web restart.
- Delayed RPC replies stay with their original connection. Turn-boundary rendering waits for durable delivery; stalled delivery requests a fresh snapshot and genuine missing anchors remain visible to integrity diagnostics.
- Process control validates process identity before stopping it. Git hook installation respects custom hook paths and linked worktrees.
- Next.js and its ESLint configuration are updated to 16.3.8, including upstream security fixes.

## Upgrade

Supports Linux and Linux on WSL, Node >=24.18.0 <25, and pnpm 9.15.9. Devin CLI must be installed and authenticated separately. Verify the source archive against SHA256SUMS; manifest.json identifies its source commit and packaging tools.

Before using the new controller on a running v0.1.0 installation, follow the **process identity registration** instructions in [operations](../operations.md). Keep the installation directory and exported service settings consistent. A web restart preserves daemon-owned turns and terminals. Applying daemon changes requires an idle maintenance window and closes its terminals. The release does not automatically update a running installation.

## 한국어

파일 복구, 세션 격리, 재시작 안전성을 보강한 유지보수 릴리스입니다.

- Discard·Undo에서 심볼릭 링크, 파일 권한, 이름 변경 전후 경로를 보존합니다. Git 작업이 실패해도 복구 수단을 제공합니다.
- 터미널 입력, 기록 응답, 전송 실패 초안, 검색 이동이 원래 세션에 연결됩니다. 명시적인 검색 대상 대신 다른 위치의 같은 문장으로 이동하지 않습니다.
- 턴을 정리하기 전에 최신 생각·계획을 저장합니다. 웹 재시작 후에도 진행 중인 모든 요청이 끝나야 대기 메시지를 실행합니다.
- 지연된 RPC 응답은 요청한 연결로만 전달합니다. 턴 종료 시 영속 기록 전달을 기다려 화면을 갱신하고, 전달이 멈추면 snapshot으로 복구합니다. 실제 앵커 누락은 계속 진단합니다.
- 프로세스 종료 전에 소유권을 확인하고, 사용자 지정 hook 경로와 linked worktree를 지원합니다.
- Next.js와 ESLint 설정을 보안 수정이 포함된 16.3.8로 갱신합니다.

실행 중인 v0.1.0을 업데이트할 때는 새 ctl 사용 전에 [운영 안내](../operations.md)의 기존 프로세스 신원 등록 절차를 적용하세요. 설치 경로와 exported 설정을 유지해야 합니다. 웹 재시작은 데몬의 작업·터미널을 유지하지만, 데몬 변경 적용은 작업 종료 후 진행해야 하며 터미널이 종료됩니다. 이 릴리스는 기존 서비스를 자동으로 업데이트하지 않습니다.

Linux·WSL의 Linux 환경, Node >=24.18.0 <25, pnpm 9.15.9를 지원합니다. 별도 Devin CLI 설치·로그인이 필요합니다. 설치 전 SHA256SUMS를 검증하고 manifest.json의 소스 커밋을 확인하세요.
