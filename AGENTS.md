## devin-web project notes

Current rules. [Decision notes](docs/decision-notes.md) explain these invariants — not a substitute.

- **Verification and deployment:** `pnpm verify` covers both TS layers, tests and lint — safe while the server runs. `pnpm install` installs the local pre-push hook, never replacing a differing one; if bypassed or a differing hook is present, run `pnpm verify` for this push. Git is required for contributor verification; source-archive install/build/start works without it. Production startup validates dependencies/build before replacing the web and never silently falls back to development or an unmanaged agent. After `pnpm build`, `bin/devin-web-ctl restart` replaces only the web build — acpd/running turns survive. Never `stop --all` during active turns; ctl re-drives detached (works from an agent PTY). ([decision notes](docs/decision-notes.md#verification-and-deployment))
- **State paths:** Resolve state via `lib/paths.mjs`: `DEVIN_WEB_STATE_DIR` → `$XDG_STATE_HOME/devin-web` → home default. Derived TS paths lazy, bin paths frozen at start, ctl shell precedence aligned. Node ≥24.18.0 and <25; pnpm 9.15.9. ([decision notes](docs/decision-notes.md#state-paths-and-runtime))
- **Search jumps:** A supplied node id is authoritative — never fall back to text outside the loaded window. Only a target without a node id may use a provisional text anchor; older live-history hits page ≤20 pages. ([decision notes](docs/decision-notes.md#search-jumps))
- **Logs, streams and supervision:** Inspect `server.log` (`[stream]`/`[diag]`/`[integrity]`/`[fatal]`), `acpd.log`, `web-watch.log`; breadcrumbs: pagehide/pageshow/vis/jserr/es-*. Streams bind to `connId#tag` — a late disconnect must not detach a replacement. Keep `devin-web-watch` health polling/restart; `ctl stop` writes `web.disabled` so stops stay down — delete it or `ctl start` to re-arm. ([decision notes](docs/decision-notes.md#logs-supervision-and-streams))
- **ACP values and view protocol:** Fresh `view` subscription = one authoritative snapshot; a reconnect inside the bounded patch log may get only missed patches. Apply patches only at `v === have + 1`; stale ignored; snapshot on gap/invalid provisional order; the separate `transcript` subscription stays. Snapshot replaces metadata + regions together. New metadata fields → `META_KEYS`, restart-persistent → `PERSISTED_META_KEYS`; optional fields removed via `clearMeta` (JSON omits `undefined`). Never `session/load` a live daemon-adopted session; take its fresh `view` snapshot, page older rows via the transcript API. Guard nullable `ev.data` with `?? {}`; `typeof`-check untyped `_meta`, never `as string`; `cognition.ai/terminalPreview` is a boolean flag — preview text is in `tool.content`. ([decision notes](docs/decision-notes.md#acp-values-and-session-view))
- **Region ownership:** Transcript = durable sessions.db rows (`message_id` keys) + server-assembled provisional items (server ids) + retained ephemera + `items` overlay for notices/request fallback. Apply regions wholesale — patch `order` + `upsert` must reproduce the server's exact count/order/content. Never merge duplicate descriptions or infer identity/position from text; `reduceEvent` handles metadata, not `session_update` turn content. ([decision notes](docs/decision-notes.md#turn-regions-and-retention))
- **Turn finalization:** `TurnRegions` owns region lifecycle. Durable rows covering an ended turn replace spine user/agent/tool items; counterpart-less thoughts/plans retain, anchored to the durable spine row they followed. `alignSpine`: tool ids exact, text roles ordinal, never by text; anchors clamp to that turn's range. Retained items sit right after anchors, never at the tail, bounded to `RETAINED_TURNS` (20) in memory + itemlog.db. Anchor above a durable row → `orphanAnchor`; out-of-turn → `server:anchorOutOfTurn`. ([decision notes](docs/decision-notes.md#turn-regions-and-retention))
- **Region transport and revisions:** Retained items ride turn-flip patches, snapshots, transcript responses — never 40ms flushes (absent key = keep client's list). `itemRev` reuses unchanged objects; assembler mutations advance `seqTo` or change done/resolved/anchor. A view snapshot replaces `state.durable`; transcript deltas/older pages extend it only within the watermark. Plan items carry ≤20 `revisions` (seq/ts/entries) only while provisional + in the itemlog payload — finalize strips them; after the flip durable `todo_write` rows are the history. `lib/client/integrity.ts` runs every flush; duplicate/sequence beacons to `/api/diag`, counted in `/api/health`, are regression alarms. ([decision notes](docs/decision-notes.md#turn-regions-and-retention))
- **Frozen watermark and seed:** Freeze `durableThrough` at a running turn's start, including adoption; withhold mid-turn durable rows until close, then advance + clear provisional. Canonical seed + frozen watermark: retain the first crossing graft edge internally, expand nested graft history only through the watermark, clip the crossing edge before display (anchors present, later rows never leak). Preserve explicit head/branch/segment + pagination semantics, canonical positions, strict read failures; idle after `forget` still reports the actual DB tip. ([decision notes](docs/decision-notes.md#frozen-watermark-and-graft-seeds))
- **Itemlog and requests:** Persist provisional on each flush to itemlog.db without blocking a turn; `ensureProvisional` restores on restart, retiring an ended logged turn once durable covers it. `runId` embedded in turn ids — a new process can't upsert into a dead turn. `client_request` assembles at arrival (`req-<requestId>`), `client_request_done` resolves it, overlay duplicates suppressed, resolved cards retire at turn boundaries, unanswered cards stay answerable. ([decision notes](docs/decision-notes.md#turn-regions-and-retention))
- **Web rejection safety:** Every detached promise gets its own `.catch()` — stream sync, `runPrompt`, terminal snapshot/detach/dropConnState, `runPrompt`'s `finally`; `writeSessionQueue` swallows its own fs errors. The `register()` uncaught/rejection guard is a log-and-survive last resort; investigate every `[fatal]`. Crash-safety tests must fail on escaped rejections. ([decision notes](docs/decision-notes.md#web-and-client-safety))
- **Client and queue safety:** Reject poisoned view events before version commit; catch/report malformed frames; isolate items with `ItemBoundary`. Ghost bubbles derive from `queueItems` (edit/drop retracts); assembler `user_message` creates the real bubble on drain. Queue mutations persist to `prompt-queue.json`, hydrate at attach, drain adopted sessions at `_devin-web/turn_end` and idle loads immediately; `q-`/`d-` ids scoped to a boot `runId`. ([decision notes](docs/decision-notes.md#web-and-client-safety))
- **Deletion, restoration and pagination:** Pause queue draining before delete RPC; success clears runtime regions/itemlog, failure resumes the preserved queue. A late turn completion keeps the old object's `deleted` marker — never revive a deleted/re-created session. Reconcile queue/running/pending before snapshot version capture; restore one-shot mode/config/command/title/usage via `PERSISTED_META_KEYS`. Restored open tool cards reconcile with final `tool_call_state` rows via newer revisions, keeping identity/position. Accept only pagination's durable rows; discard replies after session/epoch/snapshot replacement; view patches stay authoritative for retained. ([decision notes](docs/decision-notes.md#web-and-client-safety))
- **Transcript filters, grafts and cursors:** Drop falsy-`is_user_input` user nodes; absent key = user input (old DBs). Compaction roots can have null parents; grafted continuations jump parents backward over gaps of dead history. Splice each gap's newest eligible segment recursively between parent and child, excluding live main-chain members; `before` at a graft child resumes at the gap's dead tip. Splices filter through `midFinalPositions` (max `node_id`/`message_id`) so rewrites display once; expanded display-order rows map via `rowToItem`, not `rowsToTranscript`. Page tree roots via `MAX(node_id < root)`; report `truncated` whenever earlier nodes exist — never trust a full page. `?head=` walks a node's ancestry, `?branch=` resolves a subtree tip via treeIndex, `?seg=<tip>&base=<base>` bounds a work-history segment. ([decision notes](docs/decision-notes.md#transcript-grafts-and-cursors))
- **Tree index:** Upsert parent links to treecache.db by `(session_id,node_id)` with a per-session `row_id` cursor — never a per-row `root_id` cache. Forest membership = `FOREST_WALK`'s recursive CTE; keep its `CROSS JOIN`. Dirty `tree_summary_cache` on catchup; invalidate when `main_chain_id` moves even without new rows. ([decision notes](docs/decision-notes.md#tree-index))
- **Fork at node:** Advertise `clientCapabilities._meta["cognition.ai/revert"]=true` — key without underscore, methods `_cognition.ai/revert/listSteps`/`forkFromStep` with, echoed in `agentCapabilities._meta`. `supportsRevert` false → refuse (daemon-cached init needs idle restart). Covering step = smallest `forkTargetNodeId ≥ clicked node`, else newest; `forkFromStep` `{sessionId,targetNodeId}`, then `session/load` the fork id. ([decision notes](docs/decision-notes.md#fork-at-node))
- **Test environment and roots:** `test/setup-env.ts` clears `DEVIN_WEB_ACP_SOCK`/`DEVIN_WEB_HOST_SOCK` and points `DEVIN_WEB_STATE_DIR`/`DEVIN_CLI_DIR` at per-file tmpdirs — real state is unreachable by default; `NODE_ENV=development` for React `act`. `pathInRoots(p, [])` = unrestricted; implicit session-cwd roots only when nonempty — an empty list must never widen the gate. ([decision notes](docs/decision-notes.md#test-environment-and-fs-roots))
- **Daemon access, wire and restarts:** Liveness probe = `acpd.pid` + `kill(0)`, never a socket connect (first data adopts a client; older daemons displaced). `daemon.mjs`/`devin-acpd.mjs`/`host.mjs` changes apply only via `bin/devin-web-ctl acpd restart --when-idle` once `shim_state` shows all sessions `busy:false` — it kills all agent turns + host PTYs. Serve agent `fs/*_text_file` in the daemon until an initialized web client is ready, then forward unchanged; discard async replies from a replaced requester. Accept legal `{"result":null}`; survive malformed wire via guarded line loops; keep the uncaught-exception log-and-survive guard. First socket data: `_devin-web/hello` precedes the response — match replies by id, skip notifications. `shimBusy` only when `acpd-status.json` lacks `connectedClient` — HTTP failure alone is insufficient (a speaking probe displaces the bridge). On stop destroy every accepted connection incl. silent probes before `server.close()`. ([decision notes](docs/decision-notes.md#daemon-wire-and-ownership))
- **Local sequence floor and permissions:** Before the first `emit()` allocates a sequence, restore provisional + retained items and floor the counter at their max persisted `seqTo`; final tool updates need newer revisions — never replace with view versions. Agent→client request ids: opaque `req-` IDs (stable per daemon-issued request lifetime; standalone uses `req-<seq>-<random>`); `/api/sessions/:id/respond`, `respondToRequest`, `cancelRequest` bind to the route's session, `false` on mismatch. ([decision notes](docs/decision-notes.md#sequence-and-request-ownership))
- **Terminal host and backpressure:** Host PTYs stay on `host.sock` behind `terminalPool`/`terminal-remote.ts`; delayed `term/wait_for_exit` replies go only to their original socket. Trim `outputBuffer.mjs` at limit + bounded slack; honor ACP read byte limits. Stream reconnect replays `term/attach`'s snapshot by absolute offsets, skipping output `<= cursor`. Send `sessions/state` on every host connect incl. reconnects (`_host/db_changed` pushes, list liveness; host DB watch pushes changes). PTY-killing acpd restarts schedule with `--when-idle`. `writeClient`/`writeAgent` false → pause upstream + arm exactly one `drain` listener per socket; `dropClient` unpauses — a dead socket never drains. ([decision notes](docs/decision-notes.md#terminal-host-and-backpressure))
- **Hermetic E2E and fixtures:** Playwright `e2e/` stays outside Vitest; production builds in `.next-e2e` (ordinary) or `.next-daemon-e2e` (managed restart), never `next dev` or the live distDir. Sever established EventSource via the in-test TCP proxy (`context.setOffline` is insufficient). Rebuild `.e2e-fixture/` or `.daemon-e2e-fixture/` via the isolated fixture runner with `DEVIN_CLI_DIR`/`DEVIN_WEB_STATE_DIR`/`DEVIN_WEB_DEVIN_BIN`/`FAKE_ACP_SESSIONS_FILE` overrides; never touch real sessions.db/search.db or a live agent. Script fake turns via `FAKE_ACP_SCRIPT`, rewriting `turn-script.json` per test — first `match` wins, `emit`→`session/update`, `request` pauses for an answer, `session/cancel` releases cancelled. One `e2e-session-<spec>` per spec; `workers: 1`. Wait for rendered output before keyboard shortcuts; icon-only controls get `aria-label`/`title`; locked fixture `session/load` must fail for the read-only fallback. ([decision notes](docs/decision-notes.md#hermetic-e2e))
- **Sessions DB and search index:** Close every `openSessionsDb()` in `finally`. `durableThrough`/`actualMax` cache per sessions.db commit, invalidated by `onDbChange`, one-second missed-watcher backstop — never a plain time cache serving a stale-high watermark. Indexed request-path queries measured on the real DB, <50ms; heavy aggregation → search.db cursor loop. Stable source identity = `(session_id,node_id)`, never `row_id`/`src_row`; `indexed_nodes` stays linked to its FTS row, stale copies deleted on rewrite. Source `MAX(row_id)` below a cursor → wipe/rebuild. `aux_v` migrations gate transactionally (version marker); staging tables drop `IF EXISTS`; delete only invalidated `meta` keys (FTS drop invalidates `last_row_id`/`indexed_sessions_v`/`indexed_nodes`). Never truncate indexed text — dedup + `search-compact`. `aux_v4` restores capped text via `indexed_nodes.src_row`, FTS rowids unchanged; unreadable sessions.db → warn, leave `aux_v<4` for next boot. ([decision notes](docs/decision-notes.md#database-cursors-and-search))
- **CLI schema health:** Fingerprint all sessions.db tables/columns this app reads. Absent `refinery_schema_history` may yield unknown version; missing required columns mean drift; other open/query failures mean `unavailable`, never compatible. Close the probe DB in `finally`, cache five minutes, surface drift/unavailability via `/api/health` + health badge UX. ([decision notes](docs/decision-notes.md#cli-schema-health))
- **Worktrees and archives:** Isolated sessions get a fresh HEAD-based `devin-web/<slug>` worktree under `$STATE_DIR/worktrees/<slug>` as cwd for Files/Changes/terminals; sidebar groups by `worktree.repo` + branch badge. `worktrees.json` = path-keyed hints — re-stat mtime before load/save so ctl removals aren't resurrected. Delete leaves the worktree, reports `leftoverWorktree`; `worktrees rm` shows Git's dirty refusal verbatim. Archive = atomic `$STATE_DIR/archive.json` — never write sessions.db; `hidden` is a read-only mirror. Archiving hides only the sidebar entry; transcripts/search/prompts/links survive; `cleanupOld` excludes archived. ([decision notes](docs/decision-notes.md#worktrees-and-archive))
- **Git paths, mentions and prompt limits:** `--literal-pathspecs` for porcelain-derived paths in `lib/gitChanges.ts` — wildcard/bracket filenames must never match unrelated files on write. Prompt resource links encode via `mentionUri`. New queues set `mentionEncoding:"uri"`; absent = literal paths, `%20` stays encoded. Decode versioned queue previews; dequeue returns editable raw composer links; stored/drained ACP blocks stay encoded. `lib/limits.ts` governs prompt route, `ChatInput`, `experimental.proxyClientMaxBodySize`; proxy capacity ≥ `PROMPT_MAX_BODY_BYTES`. ([decision notes](docs/decision-notes.md#git-paths-and-mentions))
- **IME:** Begin every inline Enter-handling `onKeyDown` with `if (isImeComposing(e)) return;` from `lib/client/keys.ts`. ([decision notes](docs/decision-notes.md#ime))
